# App screenshots

These images are generated by the iOS app repository and copied here for deployment.

Run `pnpm sync:assets` to refresh them. `pnpm dev` and `pnpm build` run the same sync automatically. By default the
script reads the sibling `chordlist-app` repository; set `CHORDLIST_APP_REPO` when the app repository lives
elsewhere.

The iPhone captures remain in `light/` and `dark/` so existing social definitions keep working. The matching iPad
captures live in `ipad/light/` and `ipad/dark/`.

The app press-kit, social media, and App Store workflows therefore use the same reproducible screenshot outputs.
