# App screenshots

These images are generated by the iOS app repository and copied here for deployment.

Run `pnpm sync:assets` to refresh them. `pnpm dev` and `pnpm build` run the same sync automatically. By default the
script reads the sibling `progressions-swift-rork` repository; set `CHORDLIST_APP_REPO` when the app repository lives
elsewhere.

The app press-kit workflow and this website therefore use the same reproducible screenshot outputs.
