# Blog voice

How the author writes, as opposed to how the blog should be written in general — that part is
[the editorial guidelines](blog-editorial-guidelines.md). Where the two disagree on a matter of style
rather than accuracy, this file wins: the point of the refining pass is that every post sounds like
the same person, and that person is the author.

The `blog-refine` skill reads this before editing a draft and proposes additions afterwards. An entry
goes in only once the author has agreed to it and it has shown up more than once. Keep each one to a
line, with an example.

Nothing is recorded yet. The posts written before October 2026 were machine-drafted and are not a
reference for this file.
